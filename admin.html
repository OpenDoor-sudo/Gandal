Classroom & Pod Setup Guide

🎓

Mode 1: Classroom Broadcast (Projector + 25 Students)

  1. Connect the teacher PC to the classroom HDMI projector.
  2. Open http://localhost:8000/admin.html and click Create Class Code (e.g. PHYS-101).
  3. Projector displays the central lecture video on http://localhost:8000/.
  4. Students open http://<HOST-IP>:8000 on their laptops/tablets, enter the Class Code and their Student ID.
  5. When the video concludes, evaluation questions unlock simultaneously for all student desks.
🧪

Mode 2: Collaborative Pods (Self-Paced Groups)

  1. Students at a shared desk enter a shared Pod Code (e.g. POD-101) and their Student ID.
  2. Any student pressing Play, Pause, or Seek synchronizes playback across all screens in the pod in real time.
  3. Voice Priority Interlock: When a student taps the mic (🎙️), the video pauses across all pod devices and displays Locked by <Student>.
  4. ≥85% Consensus Rule: Every student in the pod must individually submit and pass the quiz (≥85%) before the pod unlocks the next lesson.
🤖

Mode 3: Solo Socratic Workstation

1:1 AI tutoring workstation with 3D Spatius Avatar, real-time Gemini voice agent, and optional USB Arduino hardware buttons/cameras.

🌐 Local Wi-Fi Pairing:

Student devices can connect via your local IP address (e.g., http://172.20.12.199:8000 or http://ventuno.local:8000). Ensure all devices are connected to the same classroom Wi-Fi network.
